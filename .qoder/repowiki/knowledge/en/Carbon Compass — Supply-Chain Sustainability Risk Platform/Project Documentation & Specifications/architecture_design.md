This module is a flat documentation repository split into two directories. `docs/` holds operational artifacts: `ENV_SETUP.md` documents backend/frontend `.env` variables (Sentinel Hub, Qwen, geocoding, Alibaba OSS), Python virtualenv + uvicorn startup, npm dev server, and the mock-mode fallback behavior when external keys are absent; it also stores UI screenshots used in pitch/demo materials. `files/` contains the canonical spec set: `PRD.md` defines the problem statement, target users, must-have features, stretch goals, success metrics, and competitive positioning; `architecture.md` describes the three-layer pipeline (Data Ingestion → AI Analysis → Presentation) with component responsibilities, the weighted scoring formula, and the full repo layout; `API_GUIDE.md` catalogs every external API (Sentinel Hub, Qwen Model Studio, geocoding, Alibaba OSS, shipping proxy) with auth, call shape, rate limits, and credential handling rules; `security.md` codifies credential management, data-handling constraints, output safety via the confidence guard, dependency hygiene, HTTPS-only communication, and a threat model table; `rules.md` enforces non-negotiable language framing ('risk signal' not 'is polluting'), phase discipline, code conventions (one module per data source, consistent `{data, confidence, source, error}` return shape), and pitch rules; `design.md`, `memory.md`, and `phases.md` provide additional design notes, team memory, and phased delivery milestones. There is no executable code — all files cross-reference each other to form a single source of truth for the project.
